# Merus Route

**Merus Route** is a lightweight Linux desktop utility designed to bridge the gap between PipeWire and direct ALSA hardware playback. It allows you to seamlessly route any running audio application straight to your hardware sound card for bit-perfect playback, bypassing intermediate software mixing layers.

## ✨ Key Features

* **Direct Hardware Routing:** Instantly routes audio from any selected application (like media players or browsers) directly to an ALSA hardware device.
* **Bit-Perfect FLAC Recorder:** Record your active audio streams directly to high-quality FLAC format in real-time, complete with a manual metadata tagging dialog (Artist, Song, Album) before saving.
* **Automatic Stream Tracking:** Automatically detects and follows your audio sources, redirecting new tracks seamlessly.
* **Volume Safety Checks:** Warns you if application or system volumes are not at 100% and provides a quick one-click reset to prevent unintended volume scaling.
* **Multi-Language Support:** Fully translated and localized interface in Romanian, English, and Italian.
* **Clean & Modern GUI:** Built with Python (Tkinter/ttk) featuring native system integration, custom iconography support, and an expandable real-time logging console.
